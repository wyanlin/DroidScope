# Android

Task 4 implements the share entry point. Build with a local Gradle installation using `gradlew.bat assembleDebug` (or `gradle assembleDebug`). The activity accepts `ACTION_SEND` and `ACTION_SEND_MULTIPLE`, including `content://` URIs, and logs URI metadata.

The launcher icon is `app/src/main/res/drawable-nodpi/app_icon.png`.
